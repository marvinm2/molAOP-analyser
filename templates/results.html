This table presents enrichment results for Key Events (KEs) Key Events are measurable biological changes essential for progression from molecular initiating event to adverse outcome in an AOP framework. based on your transcriptomic dataset.

Each row corresponds to a KE, showing the degree of overlap between its associated gene set and your differentially expressed genes.

  • Overlap Genes: Genes shared between the KE set and your dataset.
  • # Overlap: Number of overlapping genes.
  • P-value: Statistical significance from Fisher's exact test Fisher's exact test determines if a gene set is over-represented among significant genes using 2x2 contingency tables. Lower p-values indicate stronger enrichment. .
  • FDR: False Discovery Rate Adjusted p-value using Benjamini-Hochberg correction to control for multiple testing. FDR < 0.05 means less than 5% of significant results are expected to be false positives. (adjusted p-value).
  • Representation: Which way the Key Event went Both tails of Fisher's exact test are run. Enriched means more of the KE's genes responded than the background rate predicts; Depleted means fewer did — a Key Event whose machinery was conspicuously spared, which is a result in its own right. Not significant means neither tail passed the cutoff. The P-value and FDR columns describe enrichment; the depletion columns at the end of the table describe the other tail. — enriched, depleted, or not significant at the selected FDR cutoff.
  • Odds Ratio: Effect size Quantifies enrichment strength. OR > 1 indicates over-representation. For example, OR = 3.5 means genes in this KE are 3.5x more likely to be significant than expected by chance. of the enrichment.

Looking for a GMT file for fgsea / clusterProfiler? The curated KE→gene library is served by the molAOP Builder.

The enrichment was calculated using all genes in your uploaded dataset as the background universe The statistical test uses all genes in your dataset (not the entire genome) as background. This accounts for which genes were actually measured in your experiment. .

This network diagram shows how the Key Events (KEs) are connected within the selected Adverse Outcome Pathway (AOP).

Color coding:
- Node color reflects gene-level log2 fold change.
- KE nodes with a red border are significantly enriched (FDR < {{ fdr_cutoff | default(0.05) }}, Benjamini-Hochberg adjusted).
- KE nodes with a double blue border are significantly depleted — fewer of their genes responded than the background rate predicts.
- KE nodes with a dashed grey border could not be assessed (fewer than {{ ke_summary.min_ke_genes if ke_summary else 5 }} of their genes were measured).
- KE nodes with a dotted orange border are mapped, but their pathway could not be resolved to genes — a gap in this tool's reference data, not in the curation.
- Gene nodes with a green border are also significantly affected.
